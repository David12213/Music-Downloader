## How to Run

1. Install [FFmpeg](https://ffmpeg.org/). FFmpeg is neccesary for the download feature to work. It is NOT included in the app (I installed via Homebrew)
2. Go to release and download the zip of the app
3. run the app, paste your url, and download away 

## Requirements

- **Python:** Python 3.12 or up (I use 3.15)
- **Libraries:** `yt-dlp`
- **FFmpeg:** Required for MP3 conversion, downloaded separately (I downloaded via Homebrew on Mac)
